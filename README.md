## Чому цей факультет
Я переглянула сторінку з переліком факультетів на сайті НаУКМА (ukma.edu.ua)

- Факультет інформатики (fin.ukma.edu.ua);
- Факультет правничих наук (law.ukma.edu.ua);
- Києво-Могилянська школа професійної та неперервної освіти (pro.ukma.edu.ua);
- Києво-Могилянська бізнес-школа (kmbs.ua).

Решта факультетів власного сайту не має: гуманітарних наук, економічних наук,
соціальних наук і соціальних технологій, природничих наук, а також охорони
здоров'я, соціальної роботи та психології. Для них є лише внутрішні сторінки
головного сайту ukma.edu.ua
Я обрала факультет природничих наук

## Запуск

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py loaddata faculty_data
python manage.py createsuperuser
python manage.py runserver
```

Адмінка: http://127.0.0.1:8000/admin/

## Сторінки

- `/` — головна (текст редагується в адмінці)
- `/programs/`, `/programs/<id>/` — спеціальності
- `/departments/`, `/departments/<id>/` — кафедри
- `/exchange/` — програми академічного обміну (дані додає міграція)
- `/research/`, `/partners/`, `/students/` — додаткові розділи

## Дані

Інформація взята зі сторінок факультету й кафедр на ukma.edu.ua та vstup.ukma.edu.ua. 

Відповіді на питання до другої частини лежать у `ANSWERS.md`.
