# Сайт факультету природничих наук НаУКМА

Лабораторна робота з Django. Сайт для факультету природничих наук.

## Вибір факультету

Я перевірила сайти факультетів НаУКМА:

| Факультет інформатики | Окремий повноцінний сайт fin.ukma.edu.ua |
| Факультет економічних наук | Наповнений сайт на платформі university.smart.ukma.edu.ua |
| Факультет правничих наук | Наповнений реальним контентом, новин немає |
| Факультет соціальних наук і соціальних технологій | Є реальні блоки, новин немає |
| Факультет гуманітарних наук | Частково: є новини, але головний блок скопійований із шаблону |
| **Факультет природничих наук** | Лише заглушки (шість однакових текстових блоків), без новин |
| Факультет охорони здоров'я | Те саме, що й у природничих: лише заглушки |

Для роботи обрано факультет природничих наук: його сторінка на новій платформі
не містить реальної інформації, а потрібні дані (кафедри, програми, керівництво)
є на старому сайті ukma.edu.ua.

## Запуск

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py loaddata faculty_data
python manage.py createsuperuser
python manage.py runserver
```

Адмінка: http://127.0.0.1:8000/admin/

## Сторінки

- `/` — головна (текст редагується в адмінці), контакти, керівництво
- `/programs/`, `/programs/<id>/` — спеціальності
- `/departments/`, `/departments/<id>/` — кафедри
- `/research/`, `/partners/`, `/students/` — додаткові розділи

## Джерела даних

Інформація взята зі сторінок факультету та кафедр на ukma.edu.ua і vstup.ukma.edu.ua.
Частина описів написана самостійно.

Чи варто зберігати статус прийому в базі окремим полем?
Ні. Статус можна порахувати з дедлайну, тому я зробила властивість is_open, яка порівнює його з сьогоднішньою датою. Окреме поле довелося б вручну оновлювати, і воно могло б розійтися з дедлайном. Воно мало б сенс лише тоді, коли прийом закривають вручну раніше дедлайну.
